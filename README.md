# Customer Churn Analysis & Retention Dashboard

## 📌 Project Overview

Customer churn is a major challenge for telecom companies as retaining existing customers is more cost-effective than acquiring new ones. This project analyzes customer behavior to identify key factors contributing to churn and provides actionable insights to improve customer retention.

## 🎯 Objectives

* Analyze customer demographics, services, and billing information.
* Identify factors influencing customer churn.
* Build interactive dashboards for business insights.
* Develop predictive models to classify churned customers.

## 📂 Dataset

* Dataset: Telco Customer Churn Dataset
* Records: 7,043 customers
* Features: 21 attributes including customer demographics, contract details, services, and billing information.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* SQL
* Power BI

## 🔍 Data Preprocessing

* Handled missing values in `TotalCharges`
* Converted data types for analysis
* Renamed categorical values for better readability
* Performed feature engineering and data cleaning

## 📊 Exploratory Data Analysis

Key analyses performed:

* Churn distribution analysis
* Contract type analysis
* Internet service analysis
* Customer demographics analysis
* Billing and payment method analysis
* Service usage analysis

## 📈 Power BI Dashboard

The dashboard consists of four pages:

### 1. Executive Summary

* Total Customers
* Churn Rate
* Revenue Metrics
* Churn by Contract and Internet Service

### 2. Customer Demographics

* Churn by Gender
* Senior Citizen Analysis
* Partner and Dependents Analysis

### 3. Services & Billing

* Tech Support vs Churn
* Online Security vs Churn
* Payment Method Analysis
* Monthly Charges Distribution

## 💡 Key Insights

* Customers with month-to-month contracts exhibit the highest churn rates.
* Customers lacking tech support and online security are more likely to churn.
* Fiber optic users show higher churn tendencies.
* Customers with shorter tenure have significantly higher churn rates.
